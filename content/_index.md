</div>

<p class="lh-copy mw7 center f6 black-70">
國立臺灣大學「智慧車輛與機電整合實驗室」致力於自動駕駛系統開發與實車整合應用，研究對象涵蓋大客車與其他載具。技術架構包含基於深度學習的感知、定位、導航、控制、車聯網（V2X）整合，以及針對大型重型底盤設計的車輛動力學控制策略。相關研究成果已發表於多篇學術期刊與國際會議。本實驗室曾於 2019、2021 與 2023 年代表參與杜拜世界自動駕駛運輸挑戰賽（Dubai World Challenge for Self-Driving Transport）並獲得成果。其中 2019 年取得新創組亞軍，並於後續賽事中針對自駕巴士與物流運輸任務，累積實車場域測試經驗與技術優化數據。
</p>

document.addEventListener('DOMContentLoaded', function() {
const track = document.getElementById('dubaiSlider');
if(!track) return;
const images = track.children;
const imgCount = images.length;
const prevBtn = document.getElementById('dPrev');
const nextBtn = document.getElementById('dNext');
const dotContainer = document.getElementById('dDots');
let currentIndex = 0;

if (imgCount < 2) {
if(prevBtn) prevBtn.style.display = 'none';
if(nextBtn) nextBtn.style.display = 'none';
return;
}

for (let i = 0; i < imgCount; i++) {
const dot = document.createElement('div');
dot.classList.add('c-dot');
if (i === 0) dot.classList.add('active');
dot.addEventListener('click', () => goToSlide(i));
dotContainer.appendChild(dot);
}
const dots = dotContainer.querySelectorAll('.c-dot');

function goToSlide(index) {
if (index < 0) currentIndex = imgCount - 1;
else if (index >= imgCount) currentIndex = 0;
else currentIndex = index;

track.style.transform = `translateX(-${currentIndex * 100}%)`;
dots.forEach(d => d.classList.remove('active'));
dots[currentIndex].classList.add('active');
}

prevBtn.addEventListener('click', () => goToSlide(currentIndex - 1));
nextBtn.addEventListener('click', () => goToSlide(currentIndex + 1));
});
</script>

智慧車輛與機電整合實驗室開發之自主移動機器人（AMR）NTU EAT，整合多感測器融合定位與動態避障演算法。技術重點在於實現室內外環境的無縫導航，並透過物聯網技術與智慧電梯系統對接，完成機器人自動進出電梯與跨樓層垂直配送任務，解決末端物流的技術瓶頸。該系統已於台大社科院、台北花博公園等地進行多次實地運行與無人配送服務測試。透過與相關單位及物流平台合作，實驗室驗證了從訂餐、運送至取餐的全自動化流程，並持續針對校園與複雜公共空間的環境動態優化導航穩定性。
